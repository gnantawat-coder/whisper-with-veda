|---|---:|---|

## ลำดับที่จะทำให้เหมาะกับงาน Claude / ภาษาไทย–อังกฤษมากขึ้น

1. **แก้พื้นฐานก่อนเพิ่มฟีเจอร์**: กำหนด Fn ให้แอปเดียวและทำ onboarding ตรวจสิทธิ์ให้ชัดเจน; ลงนามแอปด้วย identity ที่คงที่เพื่อไม่ต้องขอสิทธิ์ใหม่เมื่ออัปเดต (ต้องมี identity จริง ไม่ bypass TCC)
2. **โหมดป้อนคำสั่งเขียนโค้ด**: glossary ที่ผู้ใช้กำหนด mapping เอง เช่น user_id, TypeScript, ชื่อไฟล์และ path; preview การแก้คำและ undo; รักษา ‘ไม่/ห้าม’, ตัวเลขและชื่อ identifier ให้ตรง หลีกเลี่ยง semantic rewrite อัตโนมัติ
3. **ไทย–อังกฤษในประโยคเดียว**: ชุดทดสอบเสียงจริงทั้งสองภาษาและ code-switching แยกวัดคำไทย/identifier/ตัวเลข; ตอนนี้ TH เน้นไทยและ EN แปลเป็นอังกฤษ ยังไม่มีการพิสูจน์ pure-English accuracy
4. **ลดเวลารอ**: วัด p50/p95 ตั้งแต่ปล่อย Fn ถึงแทรกและคำตอบเสียงแรก; streaming STT/LLM และ warm-up แบบเลือกได้ หลังวัด RAM/แบตเตอรี่จริง
5. **ถามตอบต่อเนื่องและประวัติ**: บทสนทนาใน RAM แบบล้างได้, ปุ่มอ่านซ้ำ, retry และตัวเลือกเก็บประวัติแบบเข้ารหัส; ยังไม่ควรอ่านหน้าจอหรือส่งบริบทจาก Claude โดยอัตโนมัติ

ไม่จำเป็นต้องเพิ่มภาษาอื่นหรือจ่ายค่า Claude API เพื่อปรับส่วนเหล่านี้ เป้าหมาย 90+ ต้องมีผลทดสอบใช้งานจริงเรื่องสิทธิ์ คีย์ลัด ตำแหน่งแทรก และภาษา มิใช่เพิ่มเอฟเฟกต์อย่างเดียว

## ขอบเขตรุ่น 0.1.5

- Aura สว่างตามเสียงในแถบเดิม และเต้นเบาระหว่างประมวลผล; Reduce Motion หยุด animation
- ตรวจคำขึ้นต้น Veda / เวดา / วีดา **หลังปล่อย Fn เมื่อถอดเสียงเสร็จ** ไม่ใช่ wake word ที่เปิดไมค์ตลอดเวลา; ชื่อกลางประโยคยังเป็น dictation
- ตอบด้วย Qwen3 4B Instruct บนเครื่อง ผ่าน Ollama เฉพาะ 127.0.0.1:18766, ไม่มี cloud/API key
- อ่านคำตอบ TH/EN ด้วยเสียงระบบ; Escape หยุด, Fn ครั้งใหม่หยุดเสียงก่อนเปิดไมค์
- คำตอบอ่านและคัดลอกได้ใน Settings; ไม่พิมพ์คำถามหรือคำตอบลงช่อง Claude อัตโนมัติ
- ไม่มีการอ่านจอ/ไฟล์/เว็บหรือเรียกเครื่องมือจากโมเดลถามตอบ; คำตอบอาจผิด ต้องตรวจโค้ดก่อนใช้
- รูป ×/ลูกศรไม่ใช่ view ที่ Veda สร้าง พบแถบ global dictation และ Hold-to-dictate setting ในแอป ChatGPT/Codex ที่ติดตั้ง แต่ยังยืนยันค่าคีย์ลัดจริงไม่ได้ เครื่องมือ CUA ไม่อนุญาตควบคุมแอปนี้ จึงยังไม่ได้แก้คีย์ลัดซ้อนให้

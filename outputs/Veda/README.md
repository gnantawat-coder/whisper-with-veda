# Veda 0.1.7

แอปถอดเสียงบน Mac สำหรับไทยและอังกฤษ ประมวลผลด้วย Whisper small บนเครื่อง

## ใช้งาน

เปิด `~/Applications/Veda.app` จาก Finder หรือดับเบิลคลิก `Open-Veda.command` ใน Finder เปิดซ้ำจะเรียกแถบควบคุมขึ้นมา ไม่สร้างสำเนาใหม่

- คลิกขีดเล็กเพื่อเปิดแถบ TH/EN และเลือกภาษาก่อนพูด
- TH: ถอดไทยปนศัพท์อังกฤษ; EN: พูดไทยแล้วได้ข้อความอังกฤษ
- กด Fn ค้างแล้วพูด ปล่อยเพื่อประมวลผล Escape ยกเลิก
- คลื่นเสียงอยู่ในแถบเดียวตลอด มี Aura ตามระดับเสียงขณะรับฟัง
- ไอคอนคัดลอกหมายถึงข้อความถูกพักไว้ คลิกเพื่อคัดลอกเอง
- ไอคอนคลื่นเสียงบนเมนูบาร์เปิดการตั้งค่าโดยผู้ใช้เลือกเอง Fn จะซ่อนหน้าตั้งค่าที่เปิดค้าง

**เอาโหมดถามตอบและการอ่านออกเสียงออกแล้ว** คำพูดที่มีชื่อ Veda เป็นข้อความถอดเสียงตามปกติ ไม่มี Qwen/Ollama request จากแอปอีก

## สิทธิ์และ Fn

ต้องอนุญาต Microphone เพื่อรับเสียง และ Accessibility เพื่อแทรกข้อความในแอปอื่นกับให้ Veda รับ Fn โดยตรง หากขาด Accessibility หรือไม่สามารถยืนยันช่องข้อความและตำแหน่งได้ จะพักข้อความแทนการแทรกผิดที่ ไม่กดส่งหรือวางคลิปบอร์ดอัตโนมัติ

ลายเซ็นพัฒนายังเปลี่ยนตาม binary ใหม่ สิทธิ์ที่แสดง On ใน System Settings อาจไม่ตรงกับแอปปัจจุบัน ต้องรีเฟรชผ่าน System Settings โดยยืนยัน Touch ID เอง ไม่แก้ฐานข้อมูลสิทธิ์หรือข้ามระบบอนุญาต

Fn ของ macOS ตั้งเป็น Do Nothing แล้ว Veda 0.1.7 มี event tap รับ Fn ก่อนส่งถึงแอปอื่นเมื่อ Accessibility พร้อม การป้องกันคีย์ลัดซ้อนยังต้องตรวจจากการกด Fn จริงหลังให้สิทธิ์

## การติดตั้งและ build

มีสำเนาใช้งานเดียวที่ `~/Applications/Veda.app` สำเนาเก่าอยู่ใน `work/retired-apps.noindex` แบบ `.bundle-backup` ผล build อยู่ใน `work/build-artifacts.noindex/Veda.bundle-backup` และ `Veda.zip` ไม่ทิ้งแอปซ้ำใน Spotlight

`bash scripts/test.sh` ตรวจ Core; `bash scripts/build.sh` สร้าง ZIP ลงนามแบบพัฒนา ไม่ติดตั้งอัตโนมัติ

## ผลตรวจปัจจุบัน

Build และ 30 core checks ผ่าน ตรวจภาพแถบ และทดสอบเสียงไทยสังเคราะห์→Whisper→ข้อความอังกฤษผ่าน ยังไม่ได้ยืนยันไมค์→แทรกข้อความและ Fn exclusive จริงใน 0.1.7 เพราะ macOS รอ Microphone/Accessibility และ Touch ID อยู่ ดู VALIDATION.md

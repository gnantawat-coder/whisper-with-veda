# Veda 0.1.4 — ประเมินจำลองผู้ใช้ 5 คน

นี่คือ cognitive walkthrough โดยผู้ช่วยผ่านบุคลิกและสถานการณ์สมมติ ไม่ใช่การสัมภาษณ์หรือทดลองกับคนจริง คะแนนหลังปรับเป็นการประเมิน UX ตามหน้าตา/พฤติกรรมที่สร้างและตรวจได้ ไม่ใช่หลักฐานความเร็ว ความแม่นเสียง หรือความพึงพอใจจากคนจริง

เกณฑ์ 10 คะแนน: เริ่มใช้เข้าใจง่าย 2, สถานะชัด 2, หน้าตาไม่รก 2, ควบคุมภาษา/ยกเลิก 2, กู้คืนเมื่อมีปัญหา 2

|---|---|---:|---:|---|

เฉลี่ยเชิงประเมิน: 4.8 → 7.8/10 ยังไม่ควรถือเป็นผลวิจัยผู้ใช้จริง

## สิ่งที่นำไปแก้แล้ว

- idle หนึ่งขีด 24×3 pt สีดำ opacity 0.38 ไม่มีสีส้ม/โลโก้
- recording/starting/processing/notice ใช้แคปซูลเดียวสูง 32 pt ไม่มีป้ายซ้อนด้านบนและไม่มี tooltip ของแถบซ้ำ
- TH/EN อยู่บนแถบในช่วง active; จดจำโหมดที่เลือก ไม่มีภาษาอื่น
- ข้อความพักมีปุ่มคัดลอกในแถบ; ปัญหาอื่นมีปุ่มตั้งค่าในแถบ ไม่กลบเหตุผิดพลาดด้วยข้อความพักเก่า
- ไอคอนแอปและ menu bar เปลี่ยนเป็นคลื่นเสียง 4 แท่งตามภาพอ้างอิง ไม่มีเมฆบนแถบลอย
- kernel lock ป้องกัน instance รุ่นใหม่เปิดสองแถบ; ปิดพรีวิวเก่าที่พบและยกเลิกการใช้ preview app แบบค้างทั้งระบบ
- visual QA ใช้ --render-overlays สร้าง PNG โดยไม่ติดตั้ง Fn monitor/เปิด backend/เปิดไมค์ และออกทันที

## ข้อจำกัดและการทดสอบต่อ

ต้องทดสอบกับผู้ใช้จริง 5 คนในอนาคตโดยเก็บ task completion, เวลาเข้าใจครั้งแรก, จำนวนการหลง UI, และความถูกต้องของ TH/EN แยกกัน คะแนนชุดนี้ยังไม่วัดสิ่งเหล่านั้น การพิมพ์ด้วยเสียงและแทรกข้ามแอปยังต้องให้ผู้ใช้กดเริ่มเองตามสิทธิ์ของ macOS

ภาพ HEIC ยังมีแถบปุ่ม ×/ลูกศรสีน้ำเงินที่ไม่ใช่ view ของ Veda ตาม source ที่ตรวจได้ การรวมครั้งนี้รวมทุกส่วนของ Veda ในแถบเดียว ไม่ได้เปลี่ยน UI หรือ shortcut ของแอปอื่น

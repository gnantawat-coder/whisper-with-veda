# gluu bot for Windows (lite) — รุ่นทดลอง 0.1.0

พูดภาษาไทยแล้วพิมพ์ให้ ทำงานบนเครื่องทั้งหมด ไม่มีเสียงหรือข้อความถูกส่งออกจากเครื่อง
รุ่นนี้เป็น "รุ่นเล็ก" ของ gluu bot บน Mac: มีแค่ **กดปุ่มค้าง → พูด → ปล่อย → พิมพ์** ยังไม่มีตัวละครมุมจอและ Snap Translate

> รุ่นทดลอง: ผู้พัฒนาไม่มีเครื่อง Windows ทดสอบได้แค่บนเครื่อง build ของ GitHub (ตัวถอดเสียงทำงาน, พิมพ์ภาษาไทยลงกล่องข้อความได้, ดักปุ่มได้) ไมโครโฟนจริงและการใช้งานในแอปต่าง ๆ ยังไม่เคยมีใครลอง ถ้าเจออะไรแปลก กด "คัดลอกข้อมูลเครื่อง" ในหน้าตั้งค่าแล้วส่งให้ผู้พัฒนา

## ต้องมี
- Windows 10 หรือ 11 แบบ 64-bit
- พื้นที่ว่าง 0.5–1.5 GB สำหรับโมเดลถอดเสียง
- ไมโครโฟน

## ติดตั้ง
1. แตกไฟล์ zip **ทั้งโฟลเดอร์** ไว้ที่ไหนก็ได้ (ต้องมีโฟลเดอร์ `engine` อยู่ข้าง `GluuBot.exe`)
2. ดับเบิลคลิก `GluuBot.exe` — Windows จะขึ้น "Windows protected your PC" เพราะแอปไม่ได้ซื้อใบรับรอง ให้กด **More info → Run anyway**
3. หน้าตั้งค่าจะเปิดเอง เลือกโมเดลแล้วกด **ดาวน์โหลด** (ครั้งเดียว ตรวจ checksum ให้)
   - `large-v3-q5_0` แม่นที่สุด รุ่นเดียวกับ Mac แต่ถ้าไม่มีการ์ดจอ NVIDIA จะช้า
   - `medium-q5_0` ขนาดกลาง
   - `small-q5_1` เร็วที่สุด ภาษาไทยผิดเยอะกว่า
4. รอสถานะขึ้น "พร้อม" แล้วกด **ทดสอบความเร็วด้วยไฟล์ตัวอย่าง** เพื่อดูว่าเครื่องนี้ใช้กี่วินาที ถ้าช้าเกินไปให้ลองโมเดลที่เล็กลง

### ความเร็วที่วัดได้จริง
วัดบนเครื่อง build ของ GitHub (CPU 2 คอร์ 4 เธรด ไม่มีการ์ดจอ) ด้วยเสียงตัวอย่างยาว 11 วินาที:

| โมเดล | เวลาถอดเสียง |
|---|---|
| `small-q5_1` | 7.7 วินาที |
| `medium-q5_0` | 21 วินาที |
| `large-v3-q5_0` | 42 วินาที |

เครื่องส่วนใหญ่มีคอร์มากกว่านี้และจะเร็วกว่า แต่ถ้าไม่มีการ์ดจอ NVIDIA โมเดลใหญ่จะยังช้าเกินใช้จริง ให้เริ่มที่ `small-q5_1` (ค่าเริ่มต้นของแพ็กเกจ CPU) แล้วลองขยับเป็น `medium-q5_0` ถ้าเครื่องไหว
ความเร็วบนการ์ดจอ NVIDIA ยังไม่มีใครวัด

### สองแพ็กเกจ
- `...-cpu.zip` (62 MB) ใช้ได้ทุกเครื่อง
- `...-nvidia.zip` (310 MB) สำหรับเครื่องที่มีการ์ดจอ NVIDIA และไดรเวอร์ใหม่ ใช้ CUDA 11.8 **ยังไม่เคยถูกรันเลย** เพราะเครื่อง build ไม่มีการ์ดจอ ถ้าเปิดแล้วขึ้น "เอนจินเริ่มไม่ได้" ให้กลับไปใช้แพ็กเกจ CPU แล้วส่งข้อมูลเครื่องให้ผู้พัฒนา

## ใช้งาน
| ทำอะไร | กดอะไร |
|---|---|
| พูดแล้วพิมพ์ | **กด Ctrl ขวาค้าง** พูด แล้ว**ปล่อย** ข้อความจะพิมพ์ลงช่องที่เคอร์เซอร์อยู่ |
| สลับ ไทย / แปลเป็นอังกฤษ | **Ctrl ขวา + Space** หรือคลิกขวาที่ไอคอนถาดระบบ |
| ยกเลิก | **Esc** |
| เปลี่ยนปุ่มพูด | ตั้งค่า › เปลี่ยนปุ่ม แล้วกดปุ่มที่ต้องการ (เช่น F9, Alt ขวา) |
| เปิดตั้งค่า / คัดลอกข้อความล่าสุด / ออก | คลิกขวาที่ไอคอนวงกลมดำตาฟ้าที่มุมขวาล่างของแถบงาน |

ปุ่ม Fn ใช้ไม่ได้บน Windows เพราะคีย์บอร์ดจัดการปุ่มนี้เองก่อนถึง Windows

## ถ้าใช้ไม่ได้
- **ไม่ได้ยินเสียง / ขึ้น "ไม่พบเสียงพูด"**: เปิด Settings › Privacy & security › Microphone แล้วเปิด "Let desktop apps access your microphone" และเลือกไมโครโฟนให้ถูกในหน้าตั้งค่าของ gluu bot
- **พิมพ์ไม่ลง**: Windows ไม่ให้แอปทั่วไปพิมพ์ลงหน้าต่างที่เปิดแบบ Administrator ใช้เมนู "คัดลอกข้อความล่าสุด" แล้ววางเอง
- **ช้ามาก**: เครื่องที่ไม่มีการ์ดจอ NVIDIA ถอดเสียงด้วย CPU ให้ใช้โมเดลเล็กลง
- **โปรแกรมป้องกันไวรัสเตือน**: แอปต้องดักปุ่มเพื่อรู้ว่าปุ่มพูดถูกกด มันดูแค่ปุ่มพูด, Space และ Esc ไม่บันทึกปุ่มอื่น โค้ดทั้งหมดอยู่ในโฟลเดอร์ `windows/` ของ repo นี้

## ความเป็นส่วนตัว
- เสียงอยู่ในหน่วยความจำเท่านั้น ไม่ถูกเขียนลงดิสก์ ข้อความล่าสุด 20 รายการอยู่ในหน่วยความจำและหายเมื่อปิดโปรแกรม
- ติดต่ออินเทอร์เน็ตครั้งเดียวตอนดาวน์โหลดโมเดลจาก huggingface.co
- ไฟล์ที่แอปเขียน: การตั้งค่าที่ `%APPDATA%\gluu bot\settings.json` และโมเดลที่ `C:\ProgramData\gluu bot\models`

## ถอนการติดตั้ง
ออกจากโปรแกรม (คลิกขวาไอคอน › ออก) แล้วลบโฟลเดอร์โปรแกรม, `%APPDATA%\gluu bot` และ `C:\ProgramData\gluu bot`

ตัวถอดเสียงคือ [whisper.cpp](https://github.com/ggml-org/whisper.cpp) (MIT) ดู `engine/WHISPER-LICENSE.txt`
